## 开启网页

仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。发布后以 Pages 页面显示的网址为准。

无需安装依赖或执行构建。index.html 是首页，assets 是样式和本地公式字体，problems 是单题页面，downloads 是原始文档。请保持相对目录结构。
