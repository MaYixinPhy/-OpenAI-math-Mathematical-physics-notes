## III. 对物理学研究的整体意义

### A. 哪些成果最接近物理模型本身

261、267、268、269、271 直接涉及标准量子模型中的谱、凝聚、磁化和激发。它们最重要的共同点，是处理有限系统计算难以可靠替代的无限体积或一致性问题：某个有限尺寸存在能隙，并不能排除更大系统闭隙；某个体积中有大量零动量占据，也不能自动保证热力学极限中凝聚。

263 则强调“微小物理量是巨大能量之差”的难题，260、264 强调正则性和初始数据类别。数学证明在这些地方的收益，是保证近似和极限真正保留了目标物理效应。

### B. 哪些可能成为方法上的公共基础

265 的价值在于约束二维基态的纠缠和可表示性，但算法构造仍有距离。262 的最优谱界可以进入别的变分估计。273、276 的熵结论能降低通信优化的复杂度。280、282 则把物理上常用的形式论证与局域算符、场重建和对称流的分析条件接起来。

这些工具是否真正改变研究实践，往往取决于下一阶段能否提取可计算的常数、有限规模误差、简单可检查的充分条件，以及不依赖巨大隐藏参数的构造。

### C. 三组看似冲突、实际互补的结果

**面积律和电子结构困难性：**一个特殊有隙模型类的基态可由多项式 PEPS 表达，与一般连续库仑能量问题 QMA-hard 可以同时成立。模型类、承诺条件和“存在表示／找到表示／计算观测量”的任务均不同。

**QAOA 最优性与浅电路下界：**281 允许深度随目标精度增加，并针对特殊随机优化族；274 固定深度且对所有输入要求奇偶计算优势，两者的量词和电路资源不同。

**凝聚、能隙与超流：**BEC 是一粒子密度矩阵的宏观本征值；谱隙是激发能量条件；超流涉及响应和流动稳定性。它们常有物理联系，却不能互相当作定义，更不能跨模型拼出一个额外定理。

### D. 按兴趣选择阅读顺序

- **凝聚态与张量网络：**265 → 268 → 269 → 261 → 267 → 271；从纠缠结构进入一维及二维有隙相，再看无序与有限温度。
- **原子、分子及电子结构：**263 → 262 → 278 → 275；依次理解精确多体界、谱工具、表象限制和计算复杂性。
- **量子信息与量子计算：**272 → 273 → 276 → 277 → 266 → 274 → 281 → 283 → 284 → 279；先理解资源与噪声，再进入电路和预言机模型。
- **场论、引力和弦论：**282 → 280 → 260 → 264 → 270；需要注意四维局域场论、二维手征 CFT、经典引力和矩阵量子力学分别使用不同框架。

### E. 可以据此开展的后续研究

以下是由本次梳理提出的方向，**不是原稿已经完成的成果**。

1. **证明核验优先选一个核心环节。**例如 268 的热纯度递推和有限初始化、269 的 Fock 空间界、282 的物理场重建。把主命题拆成可独立检查的引理，通常比泛泛判断一整篇“可信／不可信”更有用。
2. **从存在性走向数量级。**面积律常数、PEPS 幂次、Anderson 弱无序阈值、QAOA 深度—精度关系及 Laughlin 扰动阈值，是影响实际应用的关键。
3. **识别最值得放宽的假设。**例如均匀无序能否推广到别的独立分布；唯一基态面积律能否处理受控简并；球面赝势是否可沿有隙路径连接到 Coulomb 模型。
4. **为反例寻找可计算版本。**Kohn–Sham 构造能否降低参数规模，零密钥态能否给出便于数值或实验检查的见证，这比把存在性反例直接套在材料上更有信息量。

### 260｜时空 Penrose 不等式：黑洞面积需要多少质量

[原稿及配套材料：13 篇](sources.md#family-260) · [单题文件](problems/260.md)

#### A. 问题与历史背景

如果初始空间中已经有一个被困住的区域，远处测得的总质量能否小到不足以容纳这个黑洞？Penrose 在 1970 年代把引力坍缩、宇宙监督和黑洞面积增加联系起来，提出质量与视界面积之间的不等式。最熟悉的三维空间、无电荷形式是

```math
m\ge \sqrt{A/(16\pi)}.
```

这里采用 $G=c=1$；$m$ 是几何单位的质量，$A$ 是适当定义的面积。Schwarzschild 黑洞满足 $A=16\pi m^2$，正好取等号。物理图像是：若最终趋向静态黑洞，辐射带走能量而视界面积不能减少，那么初态质量应足以支撑该面积。但这种物理推理本身依赖演化和宇宙监督假设；从初始数据直接证明不等式，是另一项任务。

时间对称初始数据的外曲率 $K$ 为零，问题可转化为非负标量曲率下的黎曼几何。Huisken–Ilmanen、Bray 等工作解决了重要的三维时间对称情形。一般 $K\ne0$ 时，约束方程包含动量，表观视界也不是简单的极小曲面，困难显著增加。历史脉络可参阅 [Bray–Chruściel 的综述](https://arxiv.org/abs/gr-qc/0312047)及 [Mars 的综述](https://arxiv.org/abs/0906.5566)。

#### B. 稿件结论及成立范围

这一族有 13 篇稿件，包含基础不等式、等号刚性、带电和旋转推广、反例以及不同无穷远条件，不能视作一个无条件的单一定理。

中性主结果针对空间维数 $n\ge3$ 的光滑、单个渐近平坦端初始数据外部区域。在主导能量条件、弱未来被困边界、规定的微分衰减和正包围面积等假设下，声称

```math
m_{\rm ADM}=\sqrt{E_{\rm ADM}^2-|P_{\rm ADM}|^2}
\ge \frac12\left(\frac{A_{\min}}{\omega_{n-1}}\right)^{(n-2)/(n-1)}.
```

$E_{\rm ADM},P_{\rm ADM}$ 是无穷远测得的能量、动量；$\omega_{n-1}$ 是单位球面的面积；$A_{\min}$ 是原始度量中完整包围边界的截面面积下确界，**不一定等于输入边界本身的面积**。主导能量条件要求物质能量密度不小于动量密度的模。高维定理具有较强衰减条件；三、四维配套版本放宽部分条件。增加外最层、外面积极小等视界假设后，等号声称刻画 Schwarzschild–Tangherlini 外部时空的空间切片。

三维无源电磁场版本令 $Q=\sqrt{Q_E^2+Q_B^2}$、$r_A=\sqrt{A_{\min}/(4\pi)}$，得到

```math
m\ge Q,\qquad r_A\le m+\sqrt{m^2-Q^2}.
```

常见改写 $m\ge(r_A+Q^2/r_A)/2$ 仅在稿件规定的 $r_A>Q$ 分支使用。高维带电版本仅处理规定归一化的纯电场，并以配套中性定理为输入。

轴对称 Kerr–Newman 版本声称

```math
m^2\ge\frac{A}{16\pi}+\frac{Q^2}{2}
       +\frac{\pi(Q^4+4J^2)}{A}.
```

这里 $J$ 必须是包含电磁贡献的守恒总角动量；还要求规定的电真空外部拓扑、零 ADM 动量、Coulomb 型渐近、连通的外最层且外面积极小的未来边际被困边界，以及 $A\ge4\pi\sqrt{Q^4+4J^2}$。配套反例说明：若只取“裸”的引力 ADM 角动量，同时允许角向变化的较弱电磁尾部，以上公式可以失败。

其余稿件分别处理具有球形共形无穷远的渐近反 de Sitter 数据、最大切片、局部共形扰动，以及特定 Cha–Khuri–Sakovich 双曲端类别的 Bondi 质量。它们的面积、质量和衰减定义应分别使用，不能把不同版本的宽松条件拼接成一个更强命题。

#### C. 为什么证明困难，方法能带来什么

核心障碍是在把一般初始数据变形为较易处理的几何对象时，同时保护包围面积、控制无穷远质量并维持合适的曲率符号。稿件采用图形变形、共形变形和共形流等路线；刚性稿件进一步追踪每一步损失消失时的条件，恢复原始数据而不仅是一个辅助度量。

**潜在积极影响：**这些结论若经核验成立，会给数值相对论的初始数据提供严格的质量—面积一致性检查，也会强化黑洞热力学几何界限的基础。带电、旋转反例尤其有用，因为它们精确指出应测量和控制哪一种角动量及无穷远场。

**边界：**它们并不直接证明一般引力坍缩的宇宙监督，也不计算引力波波形。渐近 AdS 结果对全息研究可能提供约束，但从几何不等式到具体边界量子理论还需要额外的全息字典。

### 261｜Anderson 模型：无序为何在二维和三维表现不同

[原稿及配套材料：2 篇](sources.md#family-261) · [单题文件](problems/261.md)

#### A. 问题与历史背景

电子在无序材料中可能因多次散射的量子干涉而困在局部。Anderson 的 [1958 年论文](https://doi.org/10.1103/PhysRev.109.1492)提出了这一机制；[1979 年标度理论](https://doi.org/10.1103/PhysRevLett.42.673)预言，在适当的非相互作用、无磁场对称性类别中，二维和三维有根本差异：二维任意微弱无序也会破坏真正的金属行为，三维弱无序则可容许延展态。

代表模型为

```math
(H_{\lambda,\omega}\psi)(x)
=-\sum_{|y-x|=1}\psi(y)+\lambda\omega_x\psi(x),
\qquad x\in\mathbb Z^d.
```

$\psi$ 是单粒子波函数，跃迁能量取作单位，$\omega_x$ 是独立同分布的均匀随机变量，$\lambda>0$ 为无序强度。改用相反跃迁符号只改变能量约定。关键困难是弱无序、无限体积极限中的干涉：有限样品看起来延展，不代表热力学极限中真的延展。

#### B. 稿件结论

二维稿件针对最近邻方格、独立均匀位势 $v_x\in[-h,h]$，声称对每个固定 $h>0$，几乎必然具有完整的正规化本征态基，即整个谱为**纯点谱类型**。谱集合仍是 $[-4-h,4+h]$，本征值可在其中稠密；“纯点”并不意味着谱集合只有孤立点。

三维及更高维稿件则声称：对每个固定 $d\ge3$，存在 $\lambda_d>0$，当 $0<\lambda<\lambda_d$ 时，一个固定的非空开能量区间内几乎必然只有绝对连续谱，且该区间具有非零谱权重。能量区间依赖维数，但不随足够小的无序强度收缩；并不是说整个能带都绝对连续。三维给出存在性的正阈值，高维还提供有限矩阵方式指定阈值。

“对每个固定无序强度几乎必然”也不自动等于“有一个概率一事件同时覆盖所有实数无序强度”。二维原文明确允许概率一事件依赖 $h$。

#### C. 物理意义与限制

谱类型描述的是无限系统中能量分解的性质。纯点谱支持局域化的谱图像；绝对连续谱则为延展态和传播提供数学基础。但是要得到扩散常数、直流电导、波包均方位移的增长率，需要更强的动力学估计。二维稿件中的定能量 Green 函数估计也不能未经说明就换成对全能量、全时间统一的结论。

**潜在积极影响：**它会把经典标度图像中的维数差别推进到标准晶格模型的严格谱定理，为研究迁移率边、临界标度、有限尺寸交叉提供可靠起点。实验和数值研究可以据此更清楚地区分“局域长度超过样品尺寸”与真正的延展谱。

**边界：**这里没有电子—电子相互作用，不是多体局域化定理；均匀独立无序不能直接替换成准周期势、长程相关无序或一般连续分布。具有自旋轨道耦合、磁场或拓扑保护通道的二维系统，也不能直接套用这个结论。最有价值的后续工作是从稿件谱估计中导出可检验的传播界，并核查其对无序分布的稳健性。

### 262｜一维 Lieb–Thirring 最优常数：势阱能束缚多少负能量

[原稿及配套材料：3 篇](sources.md#family-262) · [单题文件](problems/262.md)

#### A. 问题与历史背景

把势阱做深会产生更多或更深的束缚态，但给定势阱的总体“强度预算”，负能量总量有多大？Lieb–Thirring 不等式把这个量子谱问题变成势函数的积分估计，也是研究费米子动能、排斥原理和物质稳定性的基础工具。其历史及最优常数问题可参阅 [Frank 的综述](https://arxiv.org/abs/2007.09326)。

在一维令

```math
H_W=-\frac{d^2}{dx^2}I_m-W(x),\qquad W(x)\ge0,
```

$m$ 是内部通道数，$W(x)$ 是 $m\times m$ Hermitian 矩阵。若负本征值为 $E_j$，目标是不等式

```math
\sum_j|E_j|^\gamma
\le C_\gamma\int_{\mathbb R}\operatorname{tr}
                       W(x)^{\gamma+1/2}\,dx.
```

这里取 $\hbar^2/(2m_{\rm particle})=1$，通道数 $m$ 与粒子质量无关。最优常数的问题在于：单个束缚态是否已给出最坏情形，还是许多正交态或通道耦合能提高比值？维数分析固定积分中的指数，却不能决定常数。

#### B. 稿件结论与可核对公式

三篇稿件依次处理标量常数、有限矩阵推广和所有取等情形。对每个 $1/2<\gamma<3/2$，以及满足右侧积分有限的可测非负 Hermitian 势，声称

```math
C_\gamma=
\left(\frac{\gamma-1/2}{\gamma+1/2}\right)^{\gamma-1/2}
\frac{\Gamma(\gamma+1)}{\sqrt\pi\,\Gamma(\gamma+3/2)}.
```

此常数等于标量单束缚态常数，且不随有限矩阵大小增长；一般势在不同位置无需彼此对易。所有等号势则十分特殊：在**一个与位置无关的幺正基变换**下，它们恰好分解为若干独立的 $\operatorname{sech}^2$ 势阱和零通道。

具体地，令 $r=(\gamma-1/2)^{-1}$，非零通道为

```math
w_j(x)=(r+1)a_j^2\operatorname{sech}^2
                         [ra_j(x-x_j)],\qquad a_j>0.
```

每个通道恰有一个负本征值 $-a_j^2$，尺度 $a_j$ 和中心 $x_j$ 可独立选择。尺度变换下两侧都随 $a_j^{2\gamma}$ 缩放，是公式的一项直接一致性检查。

#### C. 为什么重要

矩阵势模拟自旋、轨道或耦合波导等内部自由度。最优常数不随通道数恶化，意味着内部混合不能无限提高单位势能预算能产生的负谱权重；等号分类进一步表明，真正饱和界限时，通道必须可由一个固定基解耦。

**潜在积极影响：**可改进一维多通道量子系统的能量界、谱估计及变分计算基准；也能为研究“接近最优的势是否接近孤子形状”的稳定性问题提供起点。稿件通过变分作用量与矩阵迹比较处理正交态的竞争，而不只检验单个试探函数。

**边界：**它没有自动解决三维所有指数的最佳 Lieb–Thirring 常数，也不是新近才证明一般物质稳定。取等分类并不意味着任意接近饱和的势都有已知定量距离估计；后者是另一类稳定性定理。形式化目录列有标量主稿，不能因此把矩阵推广及等号分类一并称为已经机器核验。

### 263｜电离猜想：大原子的最外层为何仍保持有限尺度

[原稿及配套材料：3 篇](sources.md#family-263) · [单题文件](problems/263.md)

#### A. 问题与历史背景

核电荷 $Z$ 增大时，原子总能量的量级快速增长，但最外层电子的结合能、原子外部半径和可多束缚的电子数，为什么没有同样增长？这是屏蔽作用能否从完整多电子量子力学中严格推出的问题。

Thomas–Fermi 理论给出总能量的半经典主导行为，但电离能是两个很大总能量之差；即便各自的渐近展开很准确，误差仍可能淹没最外层的 $O(1)$ 能量。已有 [Solovej 的 Hartree–Fock 电离猜想结果](https://arxiv.org/abs/math-ph/0012026)表明这一图像能在重要近似理论中严格成立，本族则声称推进到完整非相对论库仑模型。

#### B. 模型和结论

取原子单位，固定 $M$ 个核的位置 $R_a$、核电荷 $Z_a\ge1$，总核电荷 $Z=\sum_aZ_a$。电子哈密顿量为

```math
H_N=\sum_{i=1}^N\left[-\frac12\Delta_i
             -\sum_{a=1}^M\frac{Z_a}{|x_i-R_a|}\right]
             +\sum_{i<j}\frac1{|x_i-x_j|}.
```

电子具有两个自旋态，在反对称费米空间中求能量下确界 $E_N$；固定核之间的常数排斥能不影响这里的电离能差。

第一篇声称存在普适常数 $C$，使

```math
E_N<E_{N-1}\quad\Longrightarrow\quad N\le Z+CM.
```

超过该电子数时不再严格结合。常数与核位置、各核电荷无关；单原子就是 $N\le Z+C$。对整数核电荷的中性原子，还声称第一电离能具有普适正的上下界；定义“外面剩余期望电子数为半个”的半径，也具有与 $Z$ 无关的正上下界。这里的“半个电子”是密度积分，绝不是电子可以被切成两半。

第二篇令 $I_m(Z)=E_{Z-m}(Z)-E_Z(Z)$，声称

```math
I_m(Z)\sim a_{\rm TF}m^{7/3},
\qquad m\to\infty,\quad Z/m\to\infty.
```

$a_{\rm TF}>0$ 是稿件原子单位下的 Thomas–Fermi 常数。第三篇以 $\int_{|x|>R_m}\rho_Z(x)\,dx=m$ 定义外层半径，声称先对固定 $m$ 取 $Z\to\infty$ 的上、下极限，再令 $m\to\infty$，两者均满足

```math
R_m\sim b_{\rm TF}m^{-1/3},\qquad
b_{\rm TF}=(81\pi^2/2)^{1/3}.
```

能量结论允许相应联合极限，半径正文主定理采用上述迭代极限；不能默默交换它们，也不声称固定 $m$ 时消除了周期表壳层造成的全部振荡。

#### C. 对物理研究的价值

**潜在积极影响：**它会从完整相互作用费米系统解释外层电子屏蔽的普适性，把“巨大的核吸引与巨大的电子排斥相互抵消”转化成可用的不等式和精确渐近律。对原子密度尾部、离子稳定性、电子结构近似的渐近约束及泛函构造都很有价值。

但 $Z\to\infty$ 是非相对论模型的数学极限；真实高核电荷体系会出现相对论及核结构效应。本族不提供每种元素电离能的高精度数值，也不替代化学中的具体电子关联计算。后续实际利用应首先提取可计算常数及有限 $Z,m$ 的误差界，而不只使用渐近指数。

### 264｜Kerr 附近的强宇宙监督：爱因斯坦方程能预测到哪里

[原稿及配套材料：3 篇](sources.md#family-264) · [单题文件](problems/264.md)

#### A. 问题与历史背景

给定满足约束的初始几何，广义相对论可以构造最大整体双曲发展，即由初始数据因果决定的最大时空。某些精确黑洞解却在内部出现 Cauchy 视界，跨过去的延拓可能不再由原始数据唯一决定。强宇宙监督猜想要求：这种可延拓性在适当意义下不是一般初始数据的行为。

旋转 Kerr 黑洞是检验场。进入内部的微弱辐射可因蓝移被放大，导致曲率或联络奇异；但“奇异”强到哪一层正则性，直接决定猜想究竟真还是假。[Dafermos–Luk 的工作](https://arxiv.org/abs/1710.01722)说明，相关动力学 Kerr 内部可以保持连续度量的可延拓性，所以只说“不能延拓”是不完整的。

#### B. 本族声称达到的正则性

固定质量 $M>0$ 和旋转参数 $0<|a|<M$ 的次极端 Kerr 背景；初始面为完整、双端、渐近平坦的 Kerr 桥附近的光滑真空数据。不要求扰动有对称性。

三篇稿件分别给出一般性的 $C^2$、$C^1$ 和更强的下述不可延拓命题：在指定加权光滑拓扑的小邻域中，可向未来延拓为**连续且非退化的度量、同时弱联络局部平方可积**的初始数据组成第一纲集；因此不可如此延拓的数据包含一个稠密 $G_\delta$ 集。常用简记为禁止

```math
g_{\rm ext}\in C^0\cap W^{1,2}_{\rm loc},
\qquad \Gamma(g_{\rm ext})\in L^2_{\rm loc},
```

其中 $\Gamma$ 是联络系数，具体延拓和坐标条件按原文定义。扩展后的时空甚至不必满足真空爱因斯坦方程。

“一般性”是 Baire 拓扑意义：不是赋予初态某个概率分布后的“概率一”，也不是所有附近数据。精确 Kerr 自身是特殊的可延拓例子，并不与该陈述冲突。邻域可依赖固定的 $M,a$；没有声称对逼近极端旋转或零旋转的参数统一。

#### C. 物理含义和后续方向

为何关注 $L^2$ 联络？爱因斯坦方程含联络的二次项；平方可积是讨论某些弱解表述时有意义的正则性门槛。阻止这种延拓，比仅仅证明曲率爆炸更接近“物理演化在弱意义下也不能继续”的问题，但仍应服从原文选定的延拓类别。

**潜在积极影响：**若核验成立，它会为旋转真空黑洞内部的决定论提供精确的局部稳定性图景，帮助区分弱零奇点、连续度量与可接受弱演化，并为数值黑洞内部研究确定该追踪哪种范数。

**边界：**双端 Kerr 桥的扰动不等同于恒星坍缩形成的单端黑洞；本族不是所有宇宙初态、所有物质模型或极端黑洞的宇宙监督证明。它也不排除只有连续度量、但联络不在 $L^2$ 中的延拓。将双端结果推进到实际坍缩数据，是独立且重要的研究方向。

### 265｜二维有隙面积律：为什么基态纠缠没有铺满体积

[原稿及配套材料：2 篇](sources.md#family-265) · [单题文件](problems/265.md)

#### A. 问题与历史背景

一般量子态需要指数数量的振幅描述，随机纯态的子区纠缠通常随体积增长；真实局域哈密顿量的低能态却往往简单得多。面积律提出，区域 $A$ 与外部的纠缠主要由边界贡献：二维中随边长而不是面积增长。这是张量网络、量子相分类和多体模拟的重要依据。

对一维有隙系统，[Hastings 在 2007 年证明面积律](https://arxiv.org/abs/0705.2024)，并建立与矩阵乘积态近似的联系。二维不能简单复制这个论证：边界本身含越来越多自由度，而相关函数指数衰减也不自动控制全部纠缠谱。

#### B. 面积律主稿的精确含义

局部维数为固定 $q$，系统定义在任意有限的方格诱导子图 $\Lambda$ 上。哈密顿量具有固定有限作用范围 $R$ 和局域强度界 $J$；唯一基态为 $|\Omega\rangle$，并假设**整个系统**具有下界 $\Delta>0$ 的谱隙：

```math
H-E_0\ge\Delta\bigl(I-|\Omega\rangle\langle\Omega|\bigr).
```

稿件声称存在只依赖 $q,R,J,\Delta$ 的常数 $C$，对任意 $A\subseteq\Lambda$ 都有

```math
S(\rho_A)=-\operatorname{Tr}\rho_A\log\rho_A
\le C\,|\partial_\Lambda A|,
\qquad \rho_A=\operatorname{Tr}_{\Lambda\setminus A}
                         |\Omega\rangle\langle\Omega|.
```

$|\partial_\Lambda A|$ 为穿过该子区边界的格点边数。常数不依赖系统和子区的大小、形状。它不要求每个局部子区截出的哈密顿量都有隙，也不以平移不变或无挫折为前提；这是结果的主要力度。

#### C. PEPS 配套结果为什么是另一项进展

第二篇针对开边界 $L\times L$ 方格上的最近邻哈密顿量，在同样的固定局域维数、强度和整体唯一基态隙条件下，声称存在非零 PEPS $|\Phi\rangle$，满足

```math
D\le C L^c,\qquad
\min_\theta\left\|\frac{\Phi}{\|\Phi\|}
                         -e^{i\theta}\Omega\right\|\le L^{-1}.
```

$D$ 是虚拟键维数；$C,c$ 只依赖固定模型界。误差控制的是归一化的**整个量子态向量**，不仅是能量密度或少数局域期望值。由纯态距离与迹距离的关系，这种误差也控制任意范数有界可观测量的期望值误差。

面积律只约束熵，是对纠缠谱的一种汇总；多项式键维数的全局 PEPS 近似需要额外控制谱尾、不同切分间的相容性和压缩误差，不能在一般情形下当作面积律的同义改写。

#### D. 对研究的积极影响与边界

**潜在积极影响：**为二维有隙相使用 PEPS 提供一般性的表达能力保证；帮助解释为什么低能多体态占据全部 Hilbert 空间中很特殊的一部分；为张量网络误差分析、基态纠缠诊断和可控近似奠定基础。

但“存在少量参数的表示”与“能在多项式时间内找到、收缩或制备它”有明显距离。稿件没有给出一般二维基态问题的高效算法，常数和幂次也未因此变成适合数值计算的规模。

唯一基态条件同样不能忽略。环面上具有拓扑简并的模型不直接属于这个陈述；带有受保护无隙边缘的开边界模型也未必满足统一整体隙。面积律的主导边界项本身不能识别拓扑序，其次领项和纠缠结构仍需单独研究。

### 266｜六维互无偏基：六能级系统能容纳几组完全互补的测量

[原稿及配套材料：2 篇](sources.md#family-266) · [单题文件](problems/266.md)

#### A. 问题与历史背景

如果在一套测量基中已确定量子态，那么用另一套基测量时所有结果等概率，这两套基就是互无偏基（MUB）。对 $d$ 维 Hilbert 空间，基 $\mathcal B_a=\{|b_i^{(a)}\rangle\}$ 与 $\mathcal B_b$ 互无偏意味着

```math
|\langle b_i^{(a)}|b_j^{(b)}\rangle|^2=1/d
\quad(a\ne b).
```

它把量子测量的互补性写成精确几何条件，与状态层析、不确定性关系和密码协议的测量设计相联系。素数幂维数可以构造 $d+1$ 套完整 MUB；$6=2\times3$ 是最小的非素数幂维数，也是长期的测试场。

已有工作构造三套，并用数值及有限离散化研究是否可能存在第四套；例如 [Raynal–Lü–Englert 的数值工作](https://arxiv.org/abs/1103.1025)和 [Jaming–Matolcsi–Móra 的离散化方案](https://arxiv.org/abs/1201.0640)。数值上找不到第四套，并不等于排除了连续参数空间中的所有可能。

#### B. 两篇稿件分别声称什么

主稿声称最大数量恰为 $N(6)=3$。其中三套的存在性不是难点；上界通过计算机辅助排除任意四套复正交基得到。原文把结论明确建立在规定的 binary64 算术、编译器条件及完整验证流水线的执行记录上。

配套稿件则证明六阶复 Hadamard 矩阵的一个 Fourier 消失猜想：在 Tao 三次根矩阵的等价类之外，特定指数向量 $(1,1,1,-1,-1,-1)$ 及其置换对应的字符和消失。它还给出排除七套完整 MUB 的整数、有理数证书，结合完成定理得到上界五。

**两份证书的逻辑力度不同：**“最多五套”的精确算术配套结果，不是“最多三套”主结果的独立完整验证。主稿的四套排除流程仍须按其自身条件检查。本报告没有执行这些计算证书。

#### C. 对物理研究的价值

六维空间可以表示单个六能级系统，也可以表示 $2\times3$ 复合系统；上界若成立，排除的是任意全空间复基，因此不是仅针对乘积测量的限制。它会告诉实验设计者：无法通过继续搜索找到理想的第四套完全互补基，应考虑近似互无偏基、一般 POVM、非对称测量设计或任务特定的优化。

这是一种“排除不可能目标”的积极影响。它能推动量子态空间几何和复 Hadamard 矩阵分类，帮助厘清“素数幂构造”背后的结构。

**边界：**三套 MUB 不足以意味着六维状态不能完整层析；可以增加非互无偏测量。它也不直接证明某个密码协议的安全率最优。实验误差允许的“近似第四套”需要定量距离界，不能单由精确不存在性推出有用的噪声阈值。

### 267｜稀薄玻色气体：正温凝聚与量子耗尽

[原稿及配套材料：5 篇](sources.md#family-267) · [单题文件](problems/267.md)

#### A. 为什么这个古老现象仍有困难

玻色凝聚是宏观数量粒子占据同一个单粒子轨道。理想气体的 Bose–Einstein 统计预言、Bogoliubov 的相互作用近似以及冷原子实验，使这一图像十分熟悉；困难在于从**真正相互作用、固定密度的无限体系**严格证明它。

例如 [Lieb–Seiringer 的受陷气体结果](https://arxiv.org/abs/math-ph/0112032)在稀薄、Gross–Pitaevskii 相关极限中严格建立凝聚，但该极限与固定相互作用、固定密度后取体积无穷的热力学极限不同。能量渐近正确也不够：不同量子态可有很接近的能量，却具有不同凝聚分数。

#### B. 正温硬球结果

系统是三维周期盒中的连续玻色气体，粒子间距离小于硬球排除距离 $a>0$ 的配置被禁止。令粒子数为 $N$、盒边长为 $L$、密度为 $\rho=N/L^3$，$\gamma^{(1)}$ 为迹等于 $N$ 的一粒子约化密度矩阵，$u_0=L^{-3/2}$ 为归一化常数轨道。

正温稿件声称：每个固定 $a>0$、每个足够小但固定的密度 $\rho>0$，都存在与体积无关的固定温度 $T(a,\rho)>0$，使精确正则 Gibbs 态满足

```math
\liminf_{L\to\infty,\ N/L^3\to\rho}
\frac{\langle u_0,\gamma^{(1)}_{N,L,T}u_0\rangle}{N}>0.
```

这是凝聚存在性，不是温度随体积趋零的伪正温结果。零温配套稿还声称任意足够稀薄硬球系统的所有基态都有统一正的凝聚分数。另一篇对固定、有界、非负、径向有限程势，给出原文单位下 $0\le T\le\rho^2$ 温区中的密度一致下界；该温标应连同其归一化阅读，不能直接把有量纲的密度平方当成普适实验温度。

#### C. 量子耗尽与 Bogoliubov 系数

即便 $T=0$，相互作用也会把部分粒子移出凝聚轨道。对硬球，以及固定有界、非负、径向、有限程且正散射长度的排斥势，两篇稿件声称

```math
1-\frac{N_0}{N}
=\frac{8}{3\sqrt\pi}\sqrt{\rho a^3}
  +o\!\left(\sqrt{\rho a^3}\right).
```

这里 $a$ 是散射长度；对该硬球约定它等于排除距离。无量纲参数 $\rho a^3\ll1$ 描述稀薄性。先在每个固定密度下取热力学极限，再令密度趋零；即使占据数没有唯一热力学极限，各积聚值也有相同的稀薄渐近。硬球稿还给出动量缩放 $k/\sqrt{8\pi\rho a}$ 下的完整 Bogoliubov 耗尽动量分布。

#### D. 对物理研究的影响

**潜在积极影响：**把用于冷原子研究的凝聚存在性、量子耗尽系数和动量分布从近似图像推进为精确模型结论，为实验拟合、量子 Monte Carlo 和有效场论提供独立基准；也使“只有散射长度进入首项”的低密度普适性具有更坚实基础。

**边界：**主定理没有确定临界温度 $T_c$、相互作用导致的 $T_c$ 偏移或临界指数；证明某个正温下凝聚也不自动确定全部凝聚温区。BEC 与超流相关但定义不同，此处不直接给出超流密度、临界速度或黏滞耗散。二维有限温系统的 BKT 物理也不在这个三维定理内。

### 268｜自旋一 Haldane 能隙：整数自旋链的经典预言

[原稿及配套材料：2 篇](sources.md#family-268) · [单题文件](problems/268.md)

#### A. 问题与历史背景

最简单的反铁磁 Heisenberg 链为

```math
H_L=J\sum_{i=1}^L\mathbf S_i\cdot\mathbf S_{i+1},
\qquad \mathbf S_{L+1}=\mathbf S_1,\qquad J>0,
```

自旋一算符满足 $\mathbf S_i^2=2$。问题是激发隙 $\gamma_L=E_1(L)-E_0(L)$ 是否在 $L\to\infty$ 时仍有正下界。

Haldane 在 [1983 年的工作](https://doi.org/10.1103/PhysRevLett.50.1153)中把长波理论与 $O(3)$ 非线性 sigma 模型联系起来，指出整数与半整数自旋的差别。其直觉来自拓扑项 $\theta=2\pi S$；但连续有效理论的推导不是对原始有限自旋晶格模型的完整数学证明。

AKLT 等可精确处理的模型支持 Haldane 相的图像，却带有额外的双二次相互作用。知道相邻可解点有隙，不等于证明连接到纯 Heisenberg 点的整个路径始终不闭隙。

#### B. 稿件结论

主稿针对**纯双线性、自旋一、偶数周期链**。以 $J=1$ 为能量单位，声称偶数 $L\ge60$ 时基态唯一，并有

```math
\gamma_L>\frac4{105}\log\frac{80}{79},
```

在偶数 $L\ge2304$ 时进一步有

```math
\gamma_L>\frac{\log20}{784}\approx0.00382.
```

恢复单位后右侧乘 $J$。这些是严格正下界的声称，不是精确能隙的测定。

配套稿针对 $2L+1$ 个格点的开链，两端加入同一固定方向的磁场，场强为原文单位下 $h=3/5$。对 $L\ge960$，声称隙大于 $\log10/392$，并通过 Tasaki 的指标定理得到边界选择的无限体积基态指标 $-1$。它不是声称所有无端场开链都具有唯一且同样有隙的低能结构；边缘自由度使两种边界条件必须分开。

#### C. 证明思路的可读版本

主稿把同一配分函数写成物理 Boltzmann 权重之和及空间转移算符的偶数矩。两个表示各自产生概率分布，用纯度 $\sum_i p_i^2$ 度量单个权重是否占主导。物理权重平方对应逆温度翻倍，空间权重平方对应链长翻倍；通过耦合估计把有限尺度证书推进到任意大偶数长度，再从 Gibbs 权重比得到谱隙。

原文声称有限初始化使用整数算术、有理区间界和显式截断误差。因此这条路线的关键不是把有限尺寸拟合外推到无限，而是可否严格完成尺度递推。本报告只核对了这一证明结构，没有复算初始化证书。

#### D. 对研究的价值及边界

**潜在积极影响：**为纯 Heisenberg 链与 Haldane 相之间的联系提供重要基础，支持对低温激发、有限相关长度、矩阵乘积态近似和受保护边缘结构的研究。转移算符—热纯度方法若可复用，也可能帮助其他难以获得有限尺寸判据的量子链。

本族不证明所有整数自旋、所有各向异性或受扰链有隙；也没有给出实际材料的交换参数。指标 $-1$ 的陈述属于指定对称性、无限体积极限和边界选择；不能只凭一个正能隙就宣布任意模型有同样的拓扑相。

### 269｜Laughlin 能隙及无序稳定性：分数量子霍尔态为何坚固

[原稿及配套材料：2 篇](sources.md#family-269) · [单题文件](problems/269.md)

#### A. 问题与历史背景

Laughlin 在 [1983 年](https://doi.org/10.1103/PhysRevLett.50.1395)提出分数量子霍尔波函数，解释强磁场二维电子形成不可压缩量子液体的机制。波函数漂亮还不够：必须证明其上方的激发能在无限系统中保持正值，才能把有限系统的精确零能态与稳定的宏观相联系起来。

Haldane 的 [球面表述](https://doi.org/10.1103/PhysRevLett.51.605)消除了真实边缘，有利于研究体相。这里处理最低 Landau 能级内的费米子 $V_1$ 赝势模型：把每对粒子的相对角动量为一的分量投影出来并罚能，

```math
H_N=\sum_{i<j}P_{ij}^{(1)}.
```

每个投影系数取一；球面磁通量子数为 $q=3(N-1)$，对应填充趋向 $1/3$ 的 Laughlin 序列。这个模型与完整 Coulomb 哈密顿量有紧密物理联系，但并不相同。

#### B. 两项主要结论

第一篇声称，对所有足够大系统，唯一 Laughlin 基态上方的谱隙至少为 $1/25$，按上述投影归一化计量。更强的算符不等式在整个最低 Landau 能级 Fock 空间中成立：

```math
H_q^2\ge\gamma H_q,\qquad
0<\gamma<\gamma_*=
4616733319001/10^{14}\approx0.04617,
```

只要磁通 $q$ 足够大，阈值不依赖粒子数。因为 $H_q\ge0$，对其谱值 $E$ 有 $E^2\ge\gamma E$，故 $E=0$ 或 $E\ge\gamma$；这是此不等式为何能排除靠近零的正能激发的直接解释。不同粒子数扇区可能有多个零模；唯一性是在指定 Laughlin 填充扇区讨论的。

第二篇令 $\varphi$ 为球面上任意实、有界、可测函数且 $\|\varphi\|_\infty\le1$，把单体势投影到最低 Landau 能级后加入

```math
H_N(\lambda)=H_N+
\lambda\sum_i P_{\rm LLL}\varphi(x_i)P_{\rm LLL}.
```

声称存在与 $N$ 及势形状无关的 $\lambda_*,\Delta_*>0$，使足够大 $N$、$|\lambda|\le\lambda_*$ 时，基态仍唯一且隙至少为 $\Delta_*$。

#### C. 为什么稳定性不是普通微扰论的小事

即使每个粒子感到的势很小，总微扰的算符范数也可以随 $N$ 增长。直接使用 $\|V\|<\Delta/2$ 的有限系统估计，会要求 $\lambda$ 随粒子数趋零；稿件声称固定正阈值仍成立，才真正触及热力学稳定性。

**潜在积极影响：**为分数霍尔体隙和对单体标量无序的鲁棒性提供严格支点，给精确对角化与密度矩阵算法提供尺度无关基准，并可能成为研究拓扑响应和局部不可区分性的基础输入。

**边界：**结论不自动覆盖 Coulomb 相互作用、Landau 能级混合、一般两体扰动、任意填充或平面边缘。它也不单独推出分数电荷、编织统计和霍尔电导量子化的全部命题。把此赝势模型沿一条可控路径连接到实验哈密顿量而不闭隙，是物理应用中的关键下一步。

### 270｜BFSS 矩阵模型的束缚态：D0 膜如何组成一个粒子

[原稿及配套材料：2 篇](sources.md#family-270) · [单题文件](problems/270.md)

#### A. 问题与历史背景

[Banks–Fischler–Shenker–Susskind 于 1996 年提出](https://arxiv.org/abs/hep-th/9610043)，十一维 M 理论可由描述 D0 膜的超对称矩阵量子力学在大 $N$ 极限中实现。玻色自由度是九个 Hermitian 矩阵 $X^I$，配有费米自由度及规范约束；矩阵本征值在适当极限中类似 D0 膜的位置。

势能包含非负的交换子平方，概念上为 $\sum_{I<J}\operatorname{Tr}[X^I,X^J]^\dagger[X^I,X^J]$。当矩阵彼此对易时，势能可以沿无界方向保持为零，因此体系具有从零开始的连续谱。零能态不因超对称代数的非负性就自动存在，更不自动平方可积。

去掉整体质心后，若 $N$ 个 D0 膜应对应一个具有给定纵向动量的基本超引力粒子，其相对运动应当有**恰好一个正规化阈值束缚态**。这正是该猜想的物理意义；“阈值”指能量处于连续谱起点。

#### B. 两篇稿件的结论并不只是相互加强

第一篇对未加质量形变的相对 $\mathrm{SU}(N)$ BFSS 模型，声称每个有限 $N\ge2$ 都有

```math
\dim\ker H_N=1.
```

该零能态平方可积，具有 $\mathrm{Spin}(9)$ 不变性，并位于原文规定的偶费米分级。这比只算超对称指标更强：在有连续谱的系统中，指标的定义、无穷远边界贡献和真正 $L^2$ 态的计数必须分开。

第二篇则针对 $N=2$ 声称存在无限多个正能正规化本征态：

```math
H\Psi_j=E_j\Psi_j,\qquad
\|\Psi_j\|=1,\qquad E_j>0,\qquad E_j\to\infty.
```

算符通过规范不变超荷二次型的闭包定义。由于该模型同时具有正能连续谱，这些态属于需要特别关注的嵌入谱现象。原文明确将其表述为反驳最初 BFSS 论文中 $N=2$ 不存在额外正规化正能态的排除性陈述。

#### C. 对物理研究的积极影响

**零能唯一性若成立，**会补牢 BFSS 多粒子解释的一块基础：不同大小的矩阵块可以分别承载一个阈值态，再讨论块之间的散射和超引力对应。它还为矩阵模型截断计算、超对称谱方法和低温模拟提供非扰动基准。

**正能态若成立，**其意义更偏修正：必须解释这些谱扇区与原有散射图景是否相容、由什么对称性或动力学机制阻止衰变，以及大 $N$ 时如何表现。反驳一个附加预言可以推动理论变得更精确，并不等于自动否定全部矩阵理论设想。

**边界：**有限 $N$ 的零模计数不能证明大 $N$ 极限与完整 M 理论等价；也不直接构造平直时空量子引力的全部散射矩阵。正能正规化本征态的结论相当强，后续核验尤其应检查算符定义域、规范约束、无穷远衰减及连续谱中的嵌入机制，而不是把有限矩阵截断中的离散本征值直接当作证据。

### 271｜Heisenberg 铁磁体：自发磁化与 Bloch 的低温定律

[原稿及配套材料：4 篇](sources.md#family-271) · [单题文件](problems/271.md)

#### A. 问题与历史背景

低温铁磁体中的长波磁振子近似具有二次色散，热激发减少磁化。Bloch 定律预言三维中的磁化亏损正比于 $T^{3/2}$。幂次来自三维动量积分和 $k^2$ 色散，是长波激发支配低温性质的代表性规律。

模型是有限量子自旋 $S=1/2,1,3/2,\ldots$ 的各向同性 Heisenberg 铁磁体。耦合 $J(r)\ge0$、$J(r)=J(-r)$ 且有限程，非零耦合的位移生成整个 $\mathbb Z^3$；后一个条件排除其实由互不连接的低维子系统拼出的情况。允许**空间方向的耦合各向异性**，但保持自旋旋转对称。

自旋波理论成功已久，严格证明却不能只把自旋算符替换成自由玻色子。[Correggi–Giuliani–Seiringer 的工作](https://arxiv.org/abs/1404.4717)已严格控制相关低温自由能；然而自由能渐近式未必可以直接对磁场求导，得到自发磁化的精确渐近。

#### B. 四篇稿件的主要结果

首先，最近邻 $d\ge3$ 模型在足够低的固定正温下存在平移不变、零场平衡 KMS 态，满足 $\omega(S_0^z)\ge S/4$。KMS 是无限量子体系热平衡的标准条件；这比某个有限盒子在显式外场下有磁化更强。

其次，定义先取体积无穷、再取正磁场趋零得到的每格点自发磁化 $m(T)$。若单磁振子在小动量处色散为

```math
\varepsilon(k)=k^{\mathsf T}Dk+O(|k|^4),\qquad D>0,
```

稿件声称，取 $k_B=1$，

```math
S-m(T)=\frac{\zeta(3/2)}{8\pi^{3/2}\sqrt{\det D}}
                  T^{3/2}+o(T^{3/2}).
```

$D$ 是由固定自旋和耦合决定的色散二次型，$\zeta$ 为 Riemann zeta 函数。这个系数可由理想磁振子积分 $\int d^3k/(2\pi)^3\,[e^{\varepsilon(k)/T}-1]^{-1}$ 得到物理直觉；稿件新增的内容，是控制真实相互作用自旋系统偏离该图像的误差。

第三篇在最近邻、原文交换能归一化下给出首个晶格修正：

```math
S-m(T)=\frac{\zeta(3/2)}{8\pi^{3/2}}(T/S)^{3/2}
+\frac{3\zeta(5/2)}{128\pi^{3/2}}(T/S)^{5/2}
+o(T^{5/2}).
```

第四篇讨论零场有限周期盒的对称态：归一化总磁化在矩意义下趋向具有确定正长度、但方向在球面均匀分布的宏观向量。这个长度等于热力学压力在零场的右导数；陈述通过自伴线性组合表达，不要求对不对易的三个自旋分量进行联合测量。

#### C. 物理意义与极限顺序

有限体积零场 Gibbs 态因旋转对称而平均磁化为零，并不否定铁磁序：它可能是许多不同方向的磁化态的对称混合。稿件把这个区别、外场选择的破缺态及 Bloch 系数联系起来。

**潜在积极影响：**为量子磁性的经典低温规律提供有限自旋的严格基础，帮助比较真实自旋模型与自由磁振子近似，并为磁化分布和晶格修正的数值研究提供明确目标。

正确顺序是体积无穷、零场右导数、最后低温极限。结论不确定 Curie 临界温度及临界指数，不直接覆盖受挫或带反铁磁键模型，也不突破一、二维短程连续对称系统中的低维限制。

### 272｜有纠缠却提不出密钥：量子资源之间不是一回事

[原稿及配套材料：1 篇](sources.md#family-272) · [单题文件](problems/272.md)

#### A. 问题与历史背景

纠缠、可蒸馏 Bell 对和可蒸馏秘密密钥是三个不同的资源概念。已有 [Horodecki 等关于束缚纠缠的工作](https://arxiv.org/abs/quant-ph/0309110)表明，某些不能蒸馏 Bell 对的纠缠态仍可产生秘密密钥。因此“不能提取纠缠”不等于“不能用于密码”。反向问题是：每个纠缠态至少都能提供一点秘密密钥吗？

秘密密钥要求 Alice 和 Bob 的输出一致、接近均匀，且与 Eve 独立。Eve 可以持有输入态的纯化；她还知道公开讨论的全部记录。仅发现 Alice 与 Bob 的相关性，尚不足以说明这种相关性对 Eve 保密。

#### B. 稿件的构造与协议范围

稿件声称构造了 $\mathbb C^{10}\otimes\mathbb C^{10}$ 上的纠缠密度矩阵 $\rho$，其值域不含非零乘积向量，同时对原文规定的局部量子 instrument 协议有 $K_D(\rho)=0$。允许联合处理任意多份拷贝、认证的双向公开通信，以及几乎必然完成的协议；输入态是唯一的共享私密资源。

结论不仅说渐近速率为零，还声称对任意份数 $n$，任何许可协议输出的一比特态 $\tau_{K_AK_BE'}$ 与任意理想秘密比特都满足

```math
\left\|\tau_{K_AK_BE'}-
\frac12\sum_{i=0}^1|ii\rangle\langle ii|\otimes\sigma_{E'}
\right\|_1\ge\frac15.
```

若采用含 $1/2$ 的通常迹距离，则下界是 $1/10$。$E'$ 包含 Eve 的输入纯化和公共记录。这种有限距离障碍比“产率很低”更明确。

同篇稿件还声称构造一个作用在 $21\times21$ 矩阵上的保迹 PPT 量子信道 $\Theta$，使 $\Theta^2$ 仍不是纠缠破坏信道，反驳 PPT-square 猜想。PPT 指 Choi 态部分转置非负；纠缠破坏则要求信道作用于任意一侧后都使双体态可分，后者更强。原文另有两个 PPT 映射的复合反例，不能把非保迹映射与保迹信道混称。

#### C. 为什么负面结论有积极价值

**潜在积极影响：**若成立，就明确分离“有纠缠”与“可在该协议类中用于秘密通信”。量子网络和资源理论将需要更精细的可用性判据；实验上测得纠缠见证，不能据此直接宣布存在正密钥率。PPT-square 反例则修正了多级噪声叠加会多快彻底破坏纠缠的某些直觉。

它不影响已经针对具体态、具体设备完成的密钥安全证明，也不说明纠缠没有其他用途。额外私密资源、催化或激活方案、改变通信模型，都必须重新与原文协议定义比较。对这种全协议量化的强结论，复核重点应是证书对多份联合处理、无限轮但几乎必然终止流程的覆盖是否完整。

### 273｜熵光子数不等式：两束量子光混合后最少有多混乱

[原稿及配套材料：1 篇](sources.md#family-273) · [单题文件](problems/273.md)

#### A. 问题与历史背景

经典熵功率不等式约束独立随机变量相加后的熵；量子光学中，对应的操作是让两束独立光经过分束器。光的能量由光子数表征，而熵还包含非经典统计和各模式之间的纠缠，因此需要合适的量子版本。

[Guha–Erkmen–Shapiro 的 2007 年论文](https://arxiv.org/abs/0710.5666)提出并讨论熵光子数不等式的通信含义。它以同熵热态的平均光子数来刻画一般态的“有效噪声”，并预期热态是极值态。

#### B. 定义与稿件结论

单模平均光子数为 $x$ 的热态熵为

```math
g(x)=(x+1)\log(x+1)-x\log x.
```

对 $n$ 模态 $\rho$，定义熵光子数 $N_S(\rho)=g^{-1}(S(\rho)/n)$；它不是一般态的真实平均光子数，而是与其每模熵相同的热态光子数。

输入为 $\rho_A\otimes\rho_B$，两输入各有 $n$ 个模式且平均总能量有限。透射率为 $\eta\in[0,1]$ 的分束器产生

```math
c_j=\sqrt\eta\,a_j+\sqrt{1-\eta}\,b_j,
\qquad j=1,\ldots,n.
```

稿件声称对保留输出 $C$ 有

```math
N_S(\rho_C)\ge\eta N_S(\rho_A)+(1-\eta)N_S(\rho_B).
```

允许 A 内部和 B 内部各自任意模式纠缠，但 A、B 之间必须独立。热态乘积输入达到等号，即使两输入熵不同也如此。$\eta=0,1$ 退化为恒等关系，是直接的端点检查。

#### C. 稿件列出的通信后果

对独立热环境的衰减信道，若环境每模光子数为 $N_B$，固定输入熵 $S_{\rm in}$ 时，输出熵下界可写为

```math
S_{\rm out}\ge
n\,g\!\left[\eta g^{-1}(S_{\rm in}/n)+(1-\eta)N_B\right],
```

并由适当热输入达到。稿件声称这对任意有限张量幂和跨模式纠缠输入成立，还给出平均光子约束下、退化的双接收者纯损耗玻色广播信道的精确经典容量区域。

**潜在积极影响：**把量子光通信中的许多最小输出熵问题压缩为热态极值问题，有助于确定噪声下的编码极限、评估高斯编码方案，并为多用户光通信提供理论基准。

**边界：**输入之间已经存在相关或纠缠时，不能直接应用该不等式；无限能量输入也不在定理内。这不是所有玻色信道的量子容量公式，不能混淆经典消息容量、量子态传输容量和秘密容量。对具体实验，还需核对损耗、记忆效应和非热噪声是否符合信道模型。

### 274｜常数深度量子电路不能算奇偶性：浅电路的能力边界

[原稿及配套材料：2 篇](sources.md#family-274) · [单题文件](problems/274.md)

#### A. 问题是什么

奇偶函数为 $\operatorname{PARITY}(x)=x_1\oplus\cdots\oplus x_n$。每一位都能影响结果，所以它是研究信息是否能在少量电路层内全局汇聚的典型问题。Moore 在 1999 年提出量子版常数深度电路类 $\mathrm{QAC}^0$ 的奇偶性猜想。

该电路允许任意单比特门和任意多控制比特的 Toffoli 门，辅助比特数为输入规模的某个多项式，各层门的支撑不重叠。它已经比只有几何局域两比特门的固定深度电路强，因此不能只用普通空间光锥大小来完成证明。[2024 年的部分进展](https://arxiv.org/abs/2410.06499)得到近线性辅助空间区间的下界。

#### B. 稿件结论

本族两篇稿件分别给出投影局域化路线与轨道剪枝路线。声称对任意固定深度 $d$、任意固定多项式次数 $c\ge1$ 和任意固定优势 $\varepsilon>0$，当 $n$ 足够大时，使用至多 $n^c$ 个总比特的此类电路不可能满足

```math
\Pr[\text{输出}=\operatorname{PARITY}(x)]
\ge\frac12+\varepsilon
\qquad\text{对所有 }x\in\{0,1\}^n.
```

辅助比特从 $|0\rangle$ 开始，最后只测量一个输出比特，其他寄存器可任意丢弃。允许保留垃圾使结论比只排除完全清理输出的算法更有意义。目录还指出通过既有归约可得到严格多数函数的对应障碍。

#### C. 历史资料核验的一处陷阱

搜索会遇到题为 *Low-degree approximation of QAC⁰ circuits* 的 2024 年预印本，其摘要仍写着已经解决问题。但 [arXiv 当前记录](https://arxiv.org/abs/2411.00976)明确标记撤稿，并说明 Lemma 2.1 不正确。不能只读搜索摘要就据此判断该问题早已解决。本报告没有把那份撤回的证明作为成立的历史结果。

#### D. 对物理研究的价值及边界

**潜在积极影响：**明确深度、辅助空间与全局信息处理之间的交换关系，帮助评估浅量子线路能否完成某类关联计算，也为状态制备和学习量子线路的下界方法提供工具。

它不是“量子计算机不能计算奇偶性”：更深的电路当然可以。也不能直接转化为任意硬件的最小运行时间；无界扇出门、中途测量、经典反馈、预先共享的纠缠辅助态等会改变模型，必须分别比较。本族两篇虽都出现在形式化目录中，本报告未运行 Comparator，也未独立检查形式命题是否逐项覆盖其物理电路语义。

### 275｜连续库仑电子问题的 QMA 困难性：困难确实来自物理模型本身

[原稿及配套材料：2 篇](sources.md#family-275) · [单题文件](problems/275.md)

#### A. 历史背景与问题

量子化学通常先选有限轨道基，再求多电子基态。一般局域量子哈密顿量的基态能量问题已与 QMA 复杂性紧密联系，但这不自动说明现实形式的连续库仑系统同样困难：构造性下界可能依赖人工自旋耦合、外磁场或额外势。

QMA 可理解为量子版的可验证证明类：验证者是多项式时间量子计算机，证明可以是量子态。一个问题 QMA-hard，意味着所有 QMA 问题都能在规定的多项式时间归约下转成它。它表达最坏情形的困难程度，不是一项无条件的“永远无法计算”定理。

[Schuch–Verstraete 的工作](https://arxiv.org/abs/0712.0483)已揭示电子结构计算与密度泛函的复杂性限制。本族进一步把限制定位到不预先截断轨道、不附加其他控制势的连续库仑哈密顿量。

#### B. 稿件结论

令 $R_a\in\mathbb Q^3$ 为彼此不同的固定核位置，电子有两个自旋态。在整个反对称连续 Hilbert 空间中研究

```math
E_0=\inf\sigma\!\left[
\sum_{i=1}^N\left(-\frac12\Delta_i
            -\sum_{a=1}^M\frac{Z_a}{|x_i-R_a|}\right)
            +\sum_{i<j}\frac1{|x_i-x_j|}\right].
```

输入还含阈值 $a<b$，承诺 $E_0\le a$ 或 $E_0\ge b$，要求区分两种情形。阈值字母 $a$ 在这里与核位置下标无关。

第一篇允许以二进制编码的正整数核电荷，因此数值大小可以很大但描述位数仍为多项式。第二篇加强为**所有核电荷都等于一**，核数和电子数都是多项式，坐标为多项式位长有理数，仍声称该判定问题 QMA-hard。归约是确定性经典多项式时间的，输出阈值间隔甚至可达到 $b-a\ge1$，按原文原子单位计量。

没有给定外磁场、有限轨道基或额外外势；对所有自旋扇区取能量下确界。也不假设输入形成稳定结合分子，因此严谨表述是“谱下确界”，不保证总有正规化基态实现它。

#### C. 为什么这个结果对物理有用

困难性归约通常把抽象的量子计算问题编码进具有受控低能有效动力学的连续电子系统，并需要证明高轨道、长程相互作用和其他自旋态不能破坏编码。去掉人为的轨道截断后，这种控制就是连接复杂性定理与真实哈密顿量形式的关键。

**潜在积极影响：**为量子化学算法设定正确目标：寻找有用结构、可控近似及典型材料中的有效方法，而不期待一个对所有几何构型都高效、精确的通用算法。它也有助于设计有理论难度保证的模拟基准。

**边界：**“所有核电荷一”不等于归约实例都是通常条件下的稳定氢分子；其几何尺度、精度及电子数仍可经过精细编码。最坏情形不能直接推断某个日常材料难算，也不否定量子计算在许多化学任务上的加速。稿件声称的是 QMA-hard，本报告不额外把整个连续问题升级为已证明属于 QMA 的 QMA-complete 问题。

### 276｜广义振幅阻尼信道：热噪声下一个量子比特能传多少经典信息

[原稿及配套材料：1 篇](sources.md#family-276) · [单题文件](problems/276.md)

#### A. 问题与历史背景

一个两能级系统与热环境耦合时，会向下衰减，也会因热激发向上跃迁。广义振幅阻尼信道（GADC）是这一过程的简单模型；它可用于理解量子存储器和通信中的弛豫噪声。

经典容量问的是：反复使用这个量子信道，最多能可靠传多少经典比特？单次最优 Holevo 信息 $\chi$ 未必等于真正容量，因为编码者可以在多次使用之间纠缠输入，解码者也可以进行联合测量。已有 [Khatri–Sharma–Wilde 的研究](https://arxiv.org/abs/1903.07747)给出多种容量界；精确消除正则化是本族声称的突破。

#### B. 可直接使用的容量公式

以 $\gamma\in[0,1]$ 表示阻尼强度，$\nu\in[0,1]$ 表示平衡激发占据。输入纯态的激发概率为 $p$ 时，输出激发概率为 $q(p)=(1-\gamma)p+\gamma\nu$。定义

```math
v(p)=\gamma\nu(1-\nu)+\gamma(1-\gamma)(p-\nu)^2,
\qquad
\lambda_-(p)=\frac{1-\sqrt{1-4v(p)}}2,
```

以及以 bit 计的二元熵 $h_2(x)=-x\log_2x-(1-x)\log_2(1-x)$。稿件声称

```math
C(\mathcal A_{\gamma,\nu})=
\max_{0\le p\le1}\bigl[h_2(q(p))-h_2(\lambda_-(p))\bigr].
```

这与原文自然对数版本相差通常的 $1/\ln2$ 单位换算。达到单次最优的是等概率二元纯态系综

```math
|\phi_\pm\rangle=\sqrt{1-p}|0\rangle\pm\sqrt p|1\rangle.
```

原文声称各次独立选择这些信号就能达到容量，接收端一般仍可用集体解码。并且

```math
\chi(\mathcal A_{\gamma,\nu}^{\otimes n})
=n\chi(\mathcal A_{\gamma,\nu}).
```

它还声称对任意有限维伙伴信道，Holevo 容量、最小输出熵和正则化经典容量具有相应强可加性。

#### C. 简单检查和实际价值

当 $\gamma=0$ 时是无噪声比特信道，上式最大值为一 bit；当 $\gamma=1$ 时输出与输入无关，两个熵相等、容量为零。两端都符合物理预期。原文的关键是证明一般热参数下的熵不等式足以排除跨使用纠缠输入的额外收益。

**潜在积极影响：**把一个需要在任意块长上优化的问题缩减为单变量最大化，提供简洁编码结构和热弛豫噪声的准确通信基准。对于评估存储等待时间、热化强度和经典读取能力的折中尤其方便。

**边界：**这是无辅助的经典容量，不是量子容量、秘密容量或纠缠辅助容量；也不自动涵盖相关噪声和记忆信道。独立信号达到 Holevo 信息不意味着任意逐个测量的接收机也达到容量。此稿列于形式化目录，但本报告未复现机器验证。

### 277｜纠缠博弈的阈值重复：量子相关不能无限规避统计放大

[原稿及配套材料：1 篇](sources.md#family-277) · [单题文件](problems/277.md)

#### A. 问题与背景

在一个双人、单轮非局域博弈中，验证者分别给 Alice、Bob 一个问题，两人不能通信，但可以预先共享纠缠，再分别作答。记允许任意有限维纠缠策略时的成功率上确界为 $v=\omega^*(G)<1$。

如果把博弈重复 $k$ 次，经典独立试验会有 Chernoff 型集中。但量子玩家可以跨全部轮次共享并联合处理纠缠，让成功事件彼此相关。因此不能直接套用独立抛硬币的概率公式。[Yuen 在 2016 年](https://arxiv.org/abs/1604.04340)为一般纠缠博弈建立了全赢概率趋零的结果；本稿声称给出更强的指数阈值界。

#### B. 稿件结论

各次的问题对独立抽样，但**同一次**中给双方的问题允许相关。设 $W_k$ 为获胜次数，双方答案字母表为 $\mathcal A,\mathcal B$。对任意 $0<\delta<1-v$，稿件声称存在普适 $\kappa_0>0$，使

```math
\Pr\!\left[W_k\ge\lceil(v+\delta)k\rceil\right]
\le\exp\!\left[-\frac{\kappa_0\delta^5}
                 {1+\log(|\mathcal A||\mathcal B|)}k\right].
```

该界对任意联合有限维策略统一，包括维数随 $k$ 增大、跨轮次的强纠缠。对固定问题分布，原文还给出分布相关的三次 $\delta$ 速率。

它不要求单轮上确界由某个有限维策略实际达到；但采用的是有限维张量积策略的上确界，不能未经论证换成更广的无限维交换算符模型。

#### C. 物理直觉及应用

若联合策略能以过大的概率持续超过单轮量子极限，那么在适当条件化和信息控制之后，应能抽取一个超过原有单轮极限的策略，产生矛盾。难点在于条件化会改变量子态，不能像经典变量那样任意复制或同时读取；原文的技术目标是控制这种信息代价。

**潜在积极影响：**加强非局域测试、交互验证及密码协议中错误概率放大的理论基础。它告诉设计者，即使被测设备跨大量测试共享复杂纠缠，超过允许阈值的作弊概率仍能指数压低。

**边界：**定理并不提供计算 $v$ 的通用高效算法，也不消除实验中的通信漏洞、抽样偏差或设备记忆问题。量子密钥分发、随机性认证等具体任务仍需要把协议转换为符合假设的博弈，并单独证明安全定义与这个阈值事件之间的联系。有限指数常数能否给出实际可用的样本量，是后续应用的重要问题。

### 278｜Kohn–Sham 系综表象的反例：相同密度未必来自一个独立粒子势

[原稿及配套材料：1 篇](sources.md#family-278) · [单题文件](problems/278.md)

#### A. 为什么这关系到密度泛函理论

[Kohn–Sham 1965 年方案](https://doi.org/10.1103/PhysRev.140.A1133)把相互作用电子密度表示为辅助非相互作用体系的轨道密度，再把复杂多体效应吸收到交换关联泛函中。这是电子结构计算的核心工具。

但有三个层次不能混为一谈：某密度来自一个多电子态；它来自相互作用外势的基态；它还能来自**一个局域非相互作用势的基态系综**。允许分数占据、混合简并基态扩大了第三类，却不在逻辑上保证包含所有物理密度。

#### B. 稿件反例

原文声称构造一个三电子 Coulomb 分子：两个相同正整数电荷 $Z$ 的固定核，放在 $\pm(D/Z)e_z$，其中 $D=10^{200}$，$Z$ 由一个有限、精确但非数值的公式指定。哈密顿量在全自旋费米空间中有正规化绝对基态，可选在 $S_z=1/2$ 扇区。

该态的自旋求和密度 $n_\Psi(x)$，不能由任何单一实、自旋无关局域势

```math
v\in L^{3/2}(\mathbb R^3)+L^\infty(\mathbb R^3)
```

对应的三电子非相互作用哈密顿量

```math
H_s(v)=\sum_{i=1}^3[-\tfrac12\Delta_i+v(x_i)]
```

的基态系综复现。换言之，不存在许可的 $v$ 和基态密度矩阵 $\Gamma$ 使 $n_\Gamma=n_\Psi$ 几乎处处成立。配套的定性表述是，对足够大的固定 $D$，所有足够大的整数 $Z$ 都有这种构造。

#### C. 阻碍在哪里

这是对一个真实相互作用基态密度的非相互作用 $v$-可表象性限制。稿件利用密度尾部在特殊平面与一般方向上的不同渐近行为，推导任何试图复现该密度的共同局域势必须违反指定函数空间条件。严格实现需要同时控制真正 Coulomb 基态、方向性尾部及非相互作用谱结构。

核电荷并没有被给成适合实验的普通元素数值。因此“有一个数学 Coulomb 分子”不能直接改写为“某种常见材料已知无法使用 Kohn–Sham 方法”。

#### D. 对物理研究的积极影响与边界

**潜在积极影响：**说明某些逆 Kohn–Sham 计算的奇异势或不收敛，可能反映表象的数学边界，而不仅是泛函不够好或数值程序有缺陷。它推动人们明确势的允许类别，研究广义 Kohn–Sham、非局域算符、自旋依赖势、有限温度或正则化等扩展。

这不反驳 Hohenberg–Kohn 理论，也不否定 Levy–Lieb 的受限搜索表述；更不说明常用 DFT 在已验证材料上失效。精确不可表象与任意精度近似可表象不同；原稿反例本身没有证明实际允许误差下近似必然失败。将这个存在性构造转化成可计算、适中核电荷的例子，是后续最有信息量的方向。

### 279｜固定有限门集的精确量子分解：把成功概率提高到严格的一

[原稿及配套材料：1 篇](sources.md#family-279) · [单题文件](problems/279.md)

#### A. 问题与历史背景

[Shor 算法](https://arxiv.org/abs/quant-ph/9508027)说明整数分解可以在量子计算机上以多项式资源和可放大的高成功率完成。这里问一个更细的问题：能否对每个输入保证输出正确、最坏情况下仍只用多项式门，而且整个算法始终来自一个固定有限门集？

“反复运行直到成功、平均时间多项式”不能保证每条随机分支都有多项式上界；“错误概率任意小”也不等于精确为零。有限门集又限制了可精确实现的旋转角度，不能给每个输入额外供应一个含答案的任意实数门。

#### B. 稿件结论

对每个整数 $N\ge2$，令输入长度 $n=\lceil\log_2(N+1)\rceil$。原文声称存在可由经典多项式时间生成的统一量子电路族，在门数与比特数均由固定多项式 $\operatorname{poly}(n)$ 控制的情况下，以概率一输出完整素因子分解，包括重数。

一个固定有限、有限作用元数的门集就足够：NOT、CNOT、Toffoli、Hadamard、$\operatorname{diag}(1,i)$，它们的逆及单控制版本。这里包括受控 Hadamard 等门，不能把定理随意改述成只用 Clifford 门。

结论属于理想电路模型的**精确函数计算**。统一性意味着生成电路的程序无需预先知道 $N$ 的分解；最坏资源界排除了把无界重复藏在“概率一最终结束”里。

#### C. 物理和计算意义

**潜在积极影响：**它会展示一个重要量子算法任务可以兼顾精确性、统一性和有限指令集，为研究量子干涉、离散门代数以及精确复杂性类提供新工具。算法结构若能迁移，可能帮助其他代数问题消除理论上的算法失败概率。

不过从普通 Shor 的高成功率到概率一，主要是复杂性理论上的增强；实际设备仍有门误差、退相干和测量误差。定理没有提供“无需纠错”的分解机器，也不自动减少资源常数，更不证明量子计算能高效解决所有 NP 完全问题。

从研究投入看，应先核验固定门集下每个精确子程序、所有测量分支的资源界和统一电路生成，再比较实际门数。对物理学的直接影响较前面的凝聚态与场论条目间接，但它属于官方数学物理分类，因此在本报告中完整保留。

### 280｜顶点算符代数与共形网：两种共形场论语言何时等价

[原稿及配套材料：1 篇](sources.md#family-280) · [单题文件](problems/280.md)

#### A. 问题与历史背景

二维共形场论的手征部分有两种重要严格表述。顶点算符代数（VOA）用场的模展开、算符乘积及代数关系描述；共形网则给圆周的每个区间指定一个可观测算符代数，直接强调局域性、Hilbert 空间和算符分析。

两种语言对应相近的物理，但形式级数中的交换关系，不自动推出闭算符及其生成的 von Neumann 代数之间的真正局域性。无界算符的定义域、能量界和闭包，是从形式 OPE 到可操作量子理论必须跨过的门槛。

[Carpi–Kawahigashi–Longo–Weiner 的工作](https://arxiv.org/abs/1503.01260)为强局域 VOA 构造共形网，并建立许多实例及反向恢复。核心后续问题是：是否能从自然的 VOA 条件本身推出强局域，而不逐模型增加分析假设？

#### B. 稿件主结果及术语

原文针对复数域上的**单、幺正、强有理** VOA $V$。单意味着没有非平凡理想，幺正提供正定内积及相容的伴随结构；强有理是一组有限性和半单性要求，按原文通常包含 CFT 型、自对偶、$C_2$-余有限及有理性条件。它比“任意幺正 VOA”窄。

稿件声称自动得到多项式能量界及 CKLW 强局域性，从而 $V$ 生成不可约且完全有理的共形网 $\mathcal A_V$。其简单分级受限模都可幺正化，融合 Hermitian 形式为正定，并有编织幺正张量范畴等价

```math
\operatorname{Rep}(V)\simeq
\operatorname{Rep}^{f}(\mathcal A_V).
```

左侧是适当有限长度的 VOA 模，右侧是共形网有限指数超选择扇区；融合、编织等结构都在共同取向约定下对应。稿件再利用既有扩张定理，连接局域有限指数网扩张与适当 VOA 共形扩张。

#### C. 对物理研究为何有帮助

超选择扇区描述不能由局域操作轻易连接的荷类型，融合说明荷怎样组合，编织记录交换结构。能证明两种表述连这些结构也一致，就允许在代数语言中做显式计算，再把结论转移到具有分析局域性控制的算符框架。

**潜在积极影响：**为有理共形场论的分类、对称扩张、orbifold 和边界手征理论提供统一基础。它也可能帮助整理拓扑相边缘的代数资料与任何子范畴之间的关系，使原来分别建立的结果可以互相使用。

**边界：**它不涵盖所有非有理、非紧致或非幺正 CFT，也不直接构造所有完整左右手征二维理论。由手征范畴到某个真实二维材料的体相，还需体边对应及具体模型输入；不能把范畴等价当成一个实验材料的直接预测。阅读原稿时，能量界如何传递到闭场强局域性，是最值得核验的桥梁。

### 281｜QAOA 达到 SK 基态能量：量子变分电路能否追上自旋玻璃极值

[原稿及配套材料：2 篇](sources.md#family-281) · [单题文件](problems/281.md)

#### A. 模型与历史背景

Sherrington–Kirkpatrick（SK）模型是全连接随机自旋玻璃的标准模型。取独立标准 Gaussian 随机耦合 $J_{ij}$，用最大化约定写

```math
C_n=\frac1{\sqrt n}\sum_{i<j}J_{ij}Z_iZ_j,
\qquad B_n=\sum_iX_i.
```

若更习惯基态最小化，可令物理哈密顿量 $H_n=-C_n$。Parisi 理论给出热力学最优能量密度 $P_*$，而找到接近它的构型是算法问题。

标准 QAOA 从 $|+\rangle^{\otimes n}$ 出发，交替实施问题演化和横场混合：

```math
|\psi_p(\gamma,\beta)\rangle
=\prod_{\ell=1}^{p}
e^{-i\beta_\ell B_n}e^{-i\gamma_\ell C_n}
|+\rangle^{\otimes n}.
```

[Farhi 等](https://arxiv.org/abs/1910.08187)研究固定深度的无限系统能量，[Basso 等](https://arxiv.org/abs/2110.14206)提出深度增加后最终达到 Parisi 值的猜想。有限深度数值性能优良，并不足以证明该极限猜想。

#### B. 稿件精确结论

记 $Q_p$ 为先取 $n\to\infty$ 后，在深度 $p$ 标准 QAOA 的确定性角度上优化得到的期望能量密度。原文声称

```math
\lim_{p\to\infty}Q_p=P_*.
```

等价地，对每个 $\varepsilon>0$，都存在某个有限深度 $p$ 及确定性角度，使热力学极限的期望能量密度至少为 $P_*-\varepsilon$。角度不依赖系统大小或具体无序实例。

必须保留量词顺序：**先选择精度和相应固定深度、固定角度，再令系统变大；随后讨论深度趋向无穷。**原文明确不给出 $p(\varepsilon)$ 的定量界，也不给出高效选角程序。它同时导出大度数随机正则图 MaxCut 的领先阶最优期望值，仍需先系统规模、后图度数的极限。

配套稿件证明零温、零场纯 SK 模型 Parisi 极小化序参量在 $[0,1)$ 上有完整相对 Stieltjes 支撑。这里的“完整支撑”指重叠尺度之间没有空缺，是对玻璃态层级结构的陈述，并不等于算法采样到了全部低能态。

#### C. 积极影响与算法边界

**潜在积极影响：**为标准 QAOA 的表达能力建立一个重要平均场基准，把变分量子线路与 Parisi 自旋玻璃理论连接起来。无序无关角度的存在也支持跨实例迁移参数的思路，并可指导寻找深度—精度关系和经典可计算的角度规则。

然而逼近每自旋能量不等于高保真制备某个基态向量，也不保证一次测量得到最优构型。存在固定精度的有限深度不意味着该深度小，或者对 $1/\varepsilon$ 多项式。SK 是特殊随机平均场族，本稿既不证明任意实例 MaxCut 的高效精确解，也不单独建立相对于最佳经典算法的量子优势。

最直接的后续研究是把存在性转成资源估计：提取 $p(\varepsilon)$、角度精度、无序实例波动和硬件编译开销，再比较可实现的经典、量子方案。

### 282｜四维尺度对称能否增强为共形对称

[原稿及配套材料：1 篇](sources.md#family-282) · [单题文件](problems/282.md)

#### A. 为什么这个问题重要

尺度不变意味着把全部长度一起放大不会改变理论；共形对称还包括局部保持角度的特殊共形变换，约束远强得多。临界点和重整化群不动点常被当作 CFT 研究，因此“尺度不变何时足以保证共形”决定了许多 bootstrap 和算符结构论证是否有基础。

在四维，幺正性、应力张量和算符谱条件相互作用，问题不能仅靠维数分析解决。[Dymarsky–Komargodski–Schwimmer–Theisen 的工作](https://arxiv.org/abs/1309.2921)给出强有力论证并讨论例外；[后续工作](https://arxiv.org/abs/1402.6322)进一步处理广义自由场等漏洞。

#### B. 核心物理障碍：virial 流

若尺度流具有

```math
D_\mu=x^\nu T_{\mu\nu}-V_\mu,\qquad
T^\mu{}_{\mu}=\partial^\mu V_\mu,
```

则尺度守恒只要求应力张量迹为一个散度，并不要求迹为零。这里 $V_\mu$ 是 virial 流。若能证明其散度等于 $\Box L$，其中 $L$ 是物理的维数二标量场，就可以在四维构造改进应力张量

```math
t_{\mu\nu}=T^{(4)}_{\mu\nu}
+\frac13(\partial_\mu\partial_\nu-\eta_{\mu\nu}\Box)L,
\qquad t^\mu{}_{\mu}=0.
```

$T^{(4)}$ 是应力张量的维数四分量，$\eta$ 为平直时空度量，$\Box=\partial^\mu\partial_\mu$。取迹时改进项给出 $-\Box L$，与原迹抵消；改进项散度为零，所以不破坏守恒。

#### C. 稿件到底证明哪一类理论

原文声称完成上述构造，但假设不只“幺正和四维”。它要求正能量、Poincaré 及尺度不变真空；缩放维数谱离散、有下界且有限重数；每个原始场只有有限个缩放维数分量；存在物理局域应力张量及实现尺度 Ward 恒等式的尺度流。

此外，原始场及伴随必须在一个因果局域的有界算符网中具有相容的 affiliated 闭算符实现。重建出的新场只有在与所有原始场的联合乘积、共同不变定义域、伴随和同一网中的局域实现均建立后，才被纳入物理场代数。这里的 affiliated 大意是无界场与相应局域有界算符代数相容；它不是仅有形式场交换关系就自动满足的条件。

在这些假设下，稿件声称 $t_{\mu\nu}$ 对称、守恒、无迹，保留平移和 Lorentz 荷；与共形 Killing 向量结合生成的流满足不破缺的**局域 Ward 恒等式**。

#### D. 对物理研究的影响及边界

**潜在积极影响：**给满足框架的四维尺度理论提供使用局域共形约束的依据；把“不动点应为 CFT”的直觉分解成可检查的场重建和算符条件；也为分析 virial 流和候选非共形尺度理论提供排除判据。

原文明确没有把局域 Ward 恒等式积分成整个有界网上的全局共形群作用。因此不能把标题概括成“所有四维尺度不变理论无条件都是全局 CFT”。离散缩放谱、有限缩放支撑或相容网实现不满足时，定理不能直接使用。弯曲背景的 Weyl 反常也不因平直空间改进张量无迹而消失。

### 283｜用布尔预言机合成任意幺正：把量子操作编码成经典查询

[原稿及配套材料：1 篇](sources.md#family-283) · [单题文件](problems/283.md)

#### A. 历史问题及直觉

制备一个给定量子态，只需要从一个已知初态得到目标；实现任意幺正 $U$ 则必须正确作用于**所有未知输入**，包括与外部参考系统纠缠的输入，因此要求更强。

Aaronson–Kuperberg 的幺正合成问题问：如果给量子算法一个可相干查询的布尔函数，能否把任意幺正变换的实现，归约为多项式数量的这种经典函数查询？[Lombardi–Ma–Wright](https://arxiv.org/abs/2310.08870)证明一次查询不够，突出了状态制备和一般过程合成之间的差别。

#### B. 稿件的量词与误差标准

原文声称存在一个仅由比特数 $n$ 决定、可在经典多项式时间生成的量子电路 $A_n$，其比特数、普通门数、预言机调用次数和查询长度均为 $\operatorname{poly}(n)$。普通门来自固定集合 $H,T,T^\dagger,\mathrm{CNOT}$。

对每个 $n$ 比特幺正 $U$，存在一个依赖 $U$ 的布尔函数 $f$，使使用可逆查询

```math
O_f|x,b\rangle=|x,b\oplus f(x)\rangle
```

后得到的输出信道 $\Phi_{n,f}$ 满足

```math
\|\Phi_{n,f}-\mathcal U\|_\diamond\le\frac12,
\qquad\mathcal U(\rho)=U\rho U^\dagger.
```

这是完整钻石范数约定，控制包括参考系统在内的最坏信道误差。量词是“存在统一电路，使对每个 $U$ 存在适配的 $f$”；不是一个固定布尔函数同时实现所有 $U$。

#### C. 它怎样避开一般幺正的指数参数数量

预言机输入长度为多项式，不代表真值表长度为多项式。若输入长 $m$，真值表可有 $2^m$ 位；任意复杂目标的信息可以藏在这张巨大表里。原文明确不声称高效构造、存储或实现这个目标依赖的布尔预言机。

因此它研究的是资源之间的归约：当某类经典函数访问被当作基本资源时，量子过程还需要多少额外资源。它不是日常门编译器，可把任意指数描述的矩阵变成无预言机的多项式大小电路。

#### D. 对物理及量子计算研究的影响

**潜在积极影响：**厘清经典函数访问与量子过程控制之间的能力关系，为预言机复杂性、量子密码和过程合成建立新的结构性工具。钻石范数保证也使结果比“某些输入上近似正确”更有组合意义。

但常数误差 $1/2$ 仍然较大，不能直接当成容错门的高精度实现；一般未知幺正的过程误差也不能像多数投票放大一个判定答案那样自动降低。高精度版本、预言机实际构造代价和具体物理 $U$ 的特殊结构，才是把这类结果转化为算法的下一步。

### 284｜经典随机与量子查询的最优幂次：总布尔函数可有近四次优势

[原稿及配套材料：1 篇](sources.md#family-284) · [单题文件](problems/284.md)

#### A. 问题与历史背景

查询复杂性把访问输入位看作主要成本，查询之间的计算不计费。令 $R(f)$ 为经典随机算法、$Q(f)$ 为量子算法计算布尔函数 $f$ 所需的最坏查询次数，均要求每个输入上错误率至多 $1/3$。

对于仅在承诺集合上定义的问题，量子查询可有很大优势；但如果 $f:\{0,1\}^n\to\{0,1\}$ 对所有输入都有定义，即**总布尔函数**，量子与经典复杂性受到普遍的多项式关系约束。Grover 搜索展示平方级优势，而它并不是所有总函数分离的唯一可能结构。

[关于 Huang 敏感性定理的量子推论](https://arxiv.org/abs/2010.12629)给出 $D(f)=O(Q(f)^4)$，其中 $D$ 为确定性查询复杂性，因而也有 $R(f)\le D(f)=O(Q(f)^4)$。剩余问题是随机算法更强，会不会普遍把四次幂降为三次幂或其他更低指数？

#### B. 稿件结论

原文声称四次幂就是最优普遍指数。对每个固定整数 $k\ge2$，构造一族总函数 $F_{k,m}$，其中 $m$ 取足够大的四的幂，使

```math
Q(F_{k,m})\le C_k\sqrt m\,(\log m)^{b_k},
\qquad
R(F_{k,m})\ge c_k\frac{m^{2-1/k}}{(\log m)^2}.
```

$c_k,C_k,b_k>0$ 是依赖 $k$ 的常数。忽略对数并以量子查询数衡量，分离幂次接近 $4-2/k$；先选择足够大的固定 $k$，再使 $m$ 变大，就能排除任何固定 $\alpha<4$ 的普遍界

```math
R(f)=O\bigl((1+Q(f))^\alpha\bigr).
```

“近四次”准确表达了这一量词结构，不应改写为稿件已构造无任何对数损失的精确 $R=Q^4$ 等式。

#### C. 为何有价值

**潜在积极影响：**刻画在最弱输入承诺条件下，量子访问还能比经典随机访问强多少，完善量子算法上限和下限的地图。构造方法也可能给其他查询或通信问题提供新的分离工具。

它使“经典能用随机性降低多少查询成本”这个问题更清楚，并提醒研究者不能把 Grover 的平方关系当作所有量子优势的普遍天花板。

**边界：**它不是任意实际计算的四次加速，更不是所有物理模拟、数据库查询或机器学习都能获得该增益。函数族可能非常人工，查询之间不计费的工作在硬件上仍然消耗时间；相干访问输入的代价也需计入应用分析。其直接贡献在量子计算理论，若要用于物理问题，还需构造既自然又保持这种分离的任务。



## V. 常用术语和记号速查

| 术语或记号 | 本文含义 |
|---|---|
| 谱隙 $\Delta$ | 基态能量与其上激发谱之间的正距离；需说明是否随体积统一 |
| 热力学极限 | 粒子数或体积趋向无穷，同时保持指定密度或局域模型参数 |
| 面积律 | 子区纠缠熵受边界大小控制，不等同于高效可计算 |
| 纯点谱／绝对连续谱 | 谱测度的类型；不能单独代替输运系数的陈述 |
| BEC | 一粒子约化密度矩阵具有随粒子数线性增长的本征值 |
| MPS／PEPS | 矩阵乘积态／投影纠缠对态；$D$ 常表示虚拟键维数 |
| KMS 态 | 无限量子系统的热平衡态条件 |
| PPT | 部分转置非负；与可分、纠缠破坏不同 |
| LOCC 类协议 | 局域量子操作与经典通信；具体允许流程必须按各稿定义 |
| $\|\cdot\|_1$ | 迹范数；通常“迹距离”还带一个 $1/2$ |
| 钻石范数 | 把任意参考系统计入的最坏量子信道距离 |
| QMA-hard | 在指定归约下至少与所有 QMA 问题一样难；属于最坏情形判断 |
| ADM／Bondi 质量 | 分别与空间无穷远／适当零无穷远结构相关的引力质量 |
| 刚性 | 不等式取等或结构满足极端条件时，模型必须具有特定形式 |
| 稠密 $G_\delta$／剩余集 | Baire 拓扑的一般性概念，不是概率分布意义的“几乎必然” |
| Ward 恒等式 | 对称性在相关函数、局域插入和守恒荷作用上的约束 |

各章节公式使用其各自定义的符号与单位。尤其 $N,m,D,\gamma$ 在不同领域有不同含义，不能跨章直接代入。
